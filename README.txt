Prospect Finder — demo package
===============================

Double-click Prospect_Finder_Demo.html to open it in any browser.
No install, no server, no internet connection needed.

Click "Find Prospects" to see the full walkthrough — a real captured
Oklahoma sample runs through the same search -> verify -> download
sequence as the live product. "Download workbook" saves the actual
Excel file included in this folder (Prospect_List_SAMPLE_Oklahoma.xlsx),
styled the same way a live run's output is.

Keep both files together in the same folder — the download button
looks for the workbook next to the HTML file.
